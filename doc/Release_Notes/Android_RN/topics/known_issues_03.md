# Known issues

Bluetooth
- Random Bluetooth security link loss in concurrent Bluetooth classic and Bluetooth LE modes with AES.
- When Bluetooth A2DP streaming is ongoing with first remote device, the DUT shows low transmit throughput with the second remote device.

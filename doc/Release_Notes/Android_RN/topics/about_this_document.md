# About this document

This document includes information about the supported features, known issues and performance of the Wi-Fi, Bluetooth and coexistence with the mentioned release.

The consolidated release has been tested with Android BSP version 16.0.0\_2.0.0, for the wireless devices mentioned in this document.

Note: Support for the 88W8997 and IW416 has been deprecated starting from Android BSP version 16.0.0_1.4.0 and is no longer included in this release.

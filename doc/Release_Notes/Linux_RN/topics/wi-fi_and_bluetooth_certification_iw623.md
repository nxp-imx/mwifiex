# Wi-Fi and Bluetooth certification

The Wi-Fi and Bluetooth certification is obtained with the following combinations.

## Wi-Fi pre-certification

-   STA – uAP \| WiFi 6E
-   STA – uAP \| WiFi 6 802.11ax
-   STA – uAP \| Wi-Fi CERTIFIED ac
-   STA – uAP \| Wi-Fi CERTIFIED n
-   STA – uAP \| PMF
-   STA \| VU
-   STA – uAP \| Security improvement
-   STA – uAP \| WPA-SAE R3
-   STA – uAP \| WPS2.0
-   STA \| Enterprise Suite B
-   STA \| Agile Multiband \(MBO\)
-   P2P

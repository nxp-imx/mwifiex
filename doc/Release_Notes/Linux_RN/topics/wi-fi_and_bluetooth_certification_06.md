# Wi-Fi and Bluetooth certification

The Wi-Fi and Bluetooth certification is obtained with the following combinations.

## WFA certifications

-   STA \| 802.11n
-   STA \| PMF
-   STA \| FFD
-   STA \| Security Improvement
-   STA \| WPA3-R3
-   STA \| VU

See [AN12976](references.md).

# Host platform {#topic_host-platform-pcie-aw693}

-   MCIMX8M-EVK platform running Linux
-   Supported Linux kernel versions: From 2.6.32 to 6.14.2
-   Interface used
    -   Wi-Fi over PCIe Interface
    -   Bluetooth/Bluetooth LE over UART Interface
-   Test Tools
    -   iPerf \(version 2.0.13\)
    -   wpa\_supplicant \(version 2.11\)
    -   hostapd \(version 2.11\)

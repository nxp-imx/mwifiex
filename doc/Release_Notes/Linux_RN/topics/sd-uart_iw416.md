# SDIO-UART IW416

## Package information

- BSP version: Linux 6.18.37_2.1.0
- Wi-Fi and Bluetooth/Bluetooth LE Firmware version 16.92.21.p164
- Driver version: MM5X16552.p22-GPL

## Version information

- Wireless SoC: IW416
- Wi-Fi and Bluetooth/Bluetooth LE Firmware version 16.92.21.p164
    - 16 - Major revision
    - 92 - Feature pack
    - 21 - Release version
    - p164 - Patch number
- Driver Version: MM6X16552.p22-GPL
    - 6X - Linux 6.x Kernel
    - 16552 - Release version
    - p22 - Patch number
    - GPL - General Public License v2

## Host platform

- MCIMX8M-EVK platform running Linux
- Supported Linux kernel versions: From 2.6.32 to 7.1
- Interface used
    - Wi-Fi over SDIO \(SDIO 3.0 support, Clock speed: 200 MHz\)
    - Bluetooth/Bluetooth LE over UART
- Test Tools
    - iPerf \(version 2.0.13\)
    - wpa\_supplicant \(version 2.11\)
    - hostapd \(version 2.11\)

**Notes**:
-	IW416 support will be discontinued in future releases. This release is the final release with IW416 support.
-	Wi-Fi and Bluetooth firmware are validated and qualified as a single combined release package. Mixing different Wi-Fi and Bluetooth firmware versions is not recommended.

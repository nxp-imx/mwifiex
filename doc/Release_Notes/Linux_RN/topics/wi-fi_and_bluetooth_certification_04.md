# Wi-Fi, Bluetooth, THread, and Matter certification

The certification is obtained with the following combinations.

## Wi-Fi pre-certification

-   STA \| WiFi6 11ax
-   STA \| Wi-Fi CERTIFIED ac
-   STA \| Wi-Fi CERTIFIED n
-   STA \| PMF
-   STA \| VU
-   STA \| FFD
-   STA \| Security Improvement
-   STA \| WPA-SAE R3
-   STA \| Agile Multiband \(MBO\)
